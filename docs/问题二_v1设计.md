# 第二问v1：点预测与固定计划的因果基线

本版对应设计的第一阶段：历史点预测、日前确定性优化、固定储能计划、实际缺口紧急结算。尚未实现误差场景、安全裕量或日内储能重调度，不称为随机问题的全局最优策略。

## 信息边界与预测

每天0:00仅向预测器传入已完成日的附件2负载和光伏电量；电价来自附件1，不读取附件3预报或附件4电价。负载候选为前周同一时段及最多4个同星期日按0.7衰减加权；光伏候选为最近3或7日同期均值。不足7日时负载回退到前日。

1月15—31日做顺序验证，候选各从6000 kWh起步，并通过1月31日的可行调度回到6000，按实际计划费+5倍紧急费比较。期末SOC目标6000，软惩罚候选为(不足,超过)=(0.2,0.05)、(0.5,0.1)、(1.0,0.2)元/kWh。共12个候选，平局按预先定义顺序选择。2月1日前锁定参数，2—12月不按实际结果重新选参数；每日历史仍自然增长。

## 1月预热与跨日

正式运行的1月使用事先固定的默认参数（负载周加权、光伏7日、不足0.5/超过0.1），不使用1月末才选出的参数回写历史。1月1日购电计划为0、电池空闲、短缺由紧急购电补齐。1月2日起正常预测调度。

普通日只有软期末目标，实际SOC跨日传递。为与无储能对照统一2月1日初始状态，1月31日通过计划充放电到6000；12月31日同样要求6000作为评价边界。这是额外的实验边界约束，不是题目要求每天循环，也不是无成本重置电量。预热期与正式期费用分别报告。

## 日前与实际执行

日前目标为预测购电费加期末SOC软惩罚，物理约束沿用第一问：充放电各90%、电网侧5000 kW、SOC1200—10800、10分钟右端代表值。严格MILP禁止同时充放电。模型只看预测，实际费用报告不包含虚拟SOC惩罚。

q、c、d均在0:00固定；先生成计划，再读取目标日实际数据结算。每段紧急电量e=max(L+c-q-G-d,0)，富余w=max(q+G+d-L-c,0)，费用=pq+5pe。执行不根据段末真实值反向修改段首控制。电量仍逐段更新，不直接用优化器SOC替代执行计算。

该版本可能在充电时发生紧急购电，也可能在计划放电时发生富余。它们是缺乏区间内保护/日内反馈的局限，必须量化披露；不擅自假定能看到整段未来真实负载，也不把这些现象隐去。富余统一称弃用电量，不全称弃光，因为也可能来自已付费计划电或放电。

## 对照与输出

正式策略与同一预测的无储能策略比较；后者q=max(预测负载-预测光伏,0)，按真实值承担同样5倍紧急费。比较双方均从6000到6000，2—12月共334天。

result2.xlsx保存334×144计划购电量、334×6个4小时实际充放电汇总及日初日末SOC、按日合并的连续紧急购电事件。计划工作表“全天购电量/费”分别指计划量/计划费；紧急量和总费用在报告及daily_summary.csv独立列出，避免费用口径混淆。无紧急购电日期保留一条空时段、零电量记录。

检查覆盖物理约束、时间连续、计划不被事后修改、费用、期末边界、原文件哈希、工作簿回读、事件合并电量守恒及1kWh故障注入。v1的费用与预测误差只能作为后续场景/滚动优化的可复现基线。
