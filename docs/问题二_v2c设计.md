# 第二问V2-C：固定V2-B购电表的储能反馈实验

## 对照范围

C0不更新场景、每小时重算；C1利用当天已结束区间的净负载更新场景、每小时重算。两者全年逐段购电量完全锁定V2-B输出，不每天重新优化购电，因此仅检验储能控制的变化。完整的“次日从新SOC重新制定购电”闭环尚未实现。

保留v1/V2-B实际1月预热；正式期2月1日以6000 kWh出发，12月31日通过可行调度回到6000。普通日仍用原6000软目标与原惩罚系数。已支付的计划费作为沉没成本，不进入滚动优化目标，但完整计入事后费用。

## 因果控制

10分钟动作精度，每小时0分重新优化当天剩余时段，只执行随后6段。更新只接受当前日已结束的净负载前缀；在时刻t使用最近结束区间的创新N[t-1]−mean_s N_s[t-1]，对未来第h段加γρ^h倍创新。场景来自V2-B同一14日历史误差，不重新选择窗口。t=0没有当日观测，修正为0。

候选为γ=0的C0，以及ρ∈{0.5,0.8,0.95}、γ∈{0.5,1.0}六个反馈配置。仅在1月15—31日选择：先重建V2-B在该验证期的固定购电及储能参考轨迹，再让候选从相同6000运行到6000，按实际费用排序。正式期不再选参。该1月开发期已反复使用，全年历史也用于过往诊断，不声称独立新测试。

## 优化与线性化

购电q固定，最小化平均场景5p紧急费加日末SOC软惩罚。剩余充放电在场景间共享；SOC从实际值开始。每次规划保留原有容量、功率和效率约束。

固定q下可用线性松弛并精确恢复互斥：若c,d同时为正，取a=min(c,d/0.81)，改为c'=c−a、d'=d−0.81a。SOC变化不变，净需求下降0.19a，正部紧急量不会增加，且功率界仍成立。因此在允许免费弃用、无循环成本的本模型中，恢复解达到松弛下界，构成物理可行最优解。若未来增加弃用惩罚或其他约束，必须重新证明，不能沿用结论。

实现保留c+d≤5000/6的凸包约束；与严格MILP在6/24/144段测试对照，并逐次重算恢复后的目标。旧控制若在新问题中仍可行且达到最优目标（1e-6元容差），继续使用，避免多解造成动作漂移。C0应保留参考方案并在费用上与V2-B一致，否则先排查而不将差异宣称反馈收益。

## 输出与审计

结果另存results/q2_v2c/与results/result2_v2c.xlsx，不覆盖V2-B。分别保存C0/C1全年逐段执行、1月候选、每小时更新日志、分月与指定日期结果。日志包括当前SOC、观测截止、创新、优化目标、参考方案是否保留。

审计不再要求实际储能动作等于0:00动作；改为检查实际动作等于最近发布的滚动指令、购电量等于冻结合同、观测截止不晚于控制发布、SOC连续和全部物理/费用关系。保留0:00参考充放电字段，避免混淆计划与执行。没有使用当前区间结束后真实值反向停充的区间内保护。
