# 第二问 V6：跨日 DP 终值函数协调与延迟鲁棒混合调度

## 1. 核心动机与架构定位

现有方案的优缺点鲜明：
- **V2-B**：利用 14 天滑动历史配对残差，在日前规划中内生化 5 倍紧急购电期望成本，实现对高额短缺惩罚的有效对冲。但每日强制 6000 kWh 软惩罚导致“跨日近视”，且充放电全天开环执行。
- **V4**：采用分段线性（PWL）下确界卷积动态规划，理论优美且无网格误差，但严重依赖即时观测（instant），在 10 分钟滞后现实下失稳，且缺乏日前主动电价套利。
- **V5 hybrid**：成功建立延迟安全门禁保护日前套利，但日前规划仍沿用 6000 kWh 惩罚，未实现跨日价值传递。

**V6 的定位**：
**“日前跨日 DP 终值函数协调 + 14 天场景鲁棒购电 + 日内一时段延迟鲁棒混合纠偏”**。
通过引入次日场景的多阶段 DP 价值函数 $V_{d+1}(S)$ 作为今日日前规划的终端影子价格，彻底取消 6000 kWh 人为软惩罚，让电池在午夜交界处的储能量自发响应次日的负荷与电价需求；日内结合基于跨日值函数反向递推的保留水平 $R_t$ 与延迟门禁进行鲁棒安全防守。

---

## 2. 数学模型与算法流

### 2.1 次日价值函数（$V_{d+1}(S)$）构建
在第 $d$ 天 00:00，利用截至第 $d-1$ 日已成熟的历史数据：
1. 预测次日负荷与光伏 $(\hat{L}_{d+1}, \hat{G}_{d+1})$；
2. 结合过去 14 天历史配对残差生成 $K=14$ 个次日净负荷场景束；
3. 在 $[1200, 10800]$ 上均匀采样 $M=9$ 个初始 SOC 点 $S_m$，求解次日两阶段风险采购 LP：
   $$C_{d+1}(S_m) = \min_{q, c, d, S, e} \sum_{t=1}^{144} p_t q_t + \frac{1}{K} \sum_{j=1}^K \sum_{t=1}^{144} 5 p_t e_{j,t}$$
   由此得到离散支撑点 $(S_m, C_m)$ 与割平面斜率 $slope_m = \frac{C_{m+1} - C_m}{S_{m+1} - S_m}$。
   因为 $C_{d+1}(S)$ 为单调递减严格凸函数，割平面构成其严格下确界包络：
   $$\theta \ge C_m + slope_m (S_{144} - S_m), \quad \forall m$$

### 2.2 今日日前规划（升级版 V2-B 风险优化）
求解单日混合整数线性规划（MILP）：
$$\min_{q, c, d, S, z, e, \theta} \sum_{t=1}^{144} p_t q_t + \frac{1}{K}\sum_{j=1}^K \sum_{t=1}^{144} 5 p_t e_{j,t} + \theta$$
约束条件：
- **割平面约束**：$\theta - slope_m S_{144} \ge C_m - slope_m S_m, \quad m=1,\dots,8$
- **储能动力学**：$S_{t+1} = S_t + 0.9 c_t - d_t / 0.9, \quad S_0 = S_{\text{act}}^{\text{yesterday}}$
- **容量与功率互斥**：$1200 \le S_t \le 10800$，$0 \le c_t \le \frac{5000}{6} z_t$，$0 \le d_t \le \frac{5000}{6} (1 - z_t)$，$z_t \in \{0, 1\}$
- **情景电力平衡**：$q_t + d_t - c_t + e_{j,t} \ge N_{j,t}, \quad e_{j,t} \ge 0$

该模型输出：今日锁定购电合同 $q_t^*$、参考套利充放电计划 $(c_t^*, d_t^*)$ 及自发优化的跨日衔接 SOC。

### 2.3 日内延迟鲁棒混合控制
1. 将次日凸值函数 $V_{d+1}(S)$ 作为终端边界，在今日 144 时段反向执行下确界卷积递推，求得各时段保留水平 $R_t^*$；
2. 在第 $t$ 个 10 分钟时段，基于一时段延迟观测残差 $\tilde{\Delta}_t = \text{observed}_{t-1} - q_t^*$：
   - 默认严格执行日前最优套利动作 $(c_t^*, d_t^*)$；
   - **熔断防线**：若 $\tilde{\Delta}_t > \text{threshold}$，强制置 $c_t = 0$，放电兜底至 $R_t^*$；
   - **富余防线**：若 $\tilde{\Delta}_t < -\text{threshold}$，强制置 $d_t = 0$，以最大功率充电吸收弃电。
   - 阈值 `threshold` 仅在 1月15—31日验证期网格优选，2—12月永久锁定。

## 3. 信息边界与验证规范

1. **因果防线**：预测、残差库及次日价值函数均只使用决策时刻已完成历史，绝不读取目标日及未来真实观测。
2. **年末边界**：12月31日通过可行充放电计划平稳回到 6000 kWh，确保与赛题评测口径严格对齐。
3. **审计覆盖**：包含电量守恒、功率互斥、SOC连续性、时延因果性、工作簿回读及哈希防篡改检查。
