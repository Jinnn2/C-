# 第二问 V6 修正版：次日成本插值与因果场景采购

旧版结果 `results/q2_v6/` 保留以供追溯，但其构造次日预测时包含当日实际值且目标错后一天，不作为有效比较结果。修正版输出 `results/q2_v6_corrected/`，入口仍为 `scripts/solve_q2_v6.py`。

## 信息与场景

第 d 日00:00仅使用 actual[:d]。今日预测保留V2B的周加权负载和七日光伏均值；次日预测取该合法历史的第二个目标日。次日残差为历史目标日 j 的实际值减去 j-1 日00:00用 actual[:j-1] 发布的预测，只纳入 j<d 的成熟样本。今日、次日各取最多14条对应提前期残差。当前模型动作在各场景间共享，目标按时段可加；不宣称利用了跨日情景身份或求得多阶段随机最优控制。

## 终值近似

在1200—10800 kWh的9个网格点求次日共享控制风险采购LP，目标为计划费加平均五倍紧急费。各点LP值精确；相邻点的线性插值是凸价值函数的上方近似，不是支撑切线下界，函数也不必严格凸。检查割线斜率非递减，以各线性段的上包络表示插值函数。

今日MILP最小化今日风险成本加此终值，取消每日6000软惩罚。下一日模型没有更远期终值，故属于约48小时有限视野近似，不能宣称无限期最优。LP互斥松弛依赖免费弃用、正购电成本及无循环奖励，可通过同时减少充放电、保持SOC并减少净需求恢复互斥。

## 执行与选参

次日终值也可用于原有逐路径PWL递推，产生保留水平；这仍是未来价值近似。有限门限候选根据上一已结束时段残差进行方向纠偏，并受保留水平约束。新增 threshold=inf 明确关闭所有纠偏及保留水平裁剪，直接执行物理可行参考计划。

1月15—31日逐候选闭环回测：每个候选按自己的实际SOC重新制定次日合同。仅输入和终值曲线可缓存，合同不能共用。费用在1e-6元内相同优先选择无纠偏候选；2—12月参数锁定。1月正式预热沿用V1，以隔离比较。1月开发数据已被多轮使用，不是独立测试集。

1月31日及12月31日采用可行参考计划回到6000，前一日的次日LP同步约束期末6000。这是共同评价边界，并非题面要求后续各问每天回到6000。最后一日禁用纠偏以确保实际终点一致。

## 验证

`python scripts/validate_q2_v6.py` 检查未来后缀扰动不影响预测/场景，完全关闭纠偏确实保留参考动作，并在三个不同季节的日期比较九点插值规划与相同输入的直接48小时规划。后者只验证采样日期的近似误差，不能证明所有日期误差界。全年执行另检查供需、SOC连续、互斥、费用、混合规则及Excel回读。输出完整每日求解状态与耗时。

## 复现

OPENBLAS_NUM_THREADS=1 python scripts/validate_q2_v6.py
