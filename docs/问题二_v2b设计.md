# 第二问V2-B：历史误差场景购电

## 唯一变化

沿用V2-A选定的预测（当前为v1基础预测、零偏差修正），在日前目标中加入场景期望紧急费。购电、充电、放电和SOC在场景间共享，且仍全天固定执行。不加入区间内保护、日内重调度、额外购电安全系数或CVaR。

目标为 Σp q + (1/K)ΣsΣt 5p e[s,t] + 期末SOC软惩罚。场景约束为 q+d+e[s]≥L[s]−G[s]+c，非负富余可隐式弃用。逐场景e≥0；正电价确保最优e等于实际短缺正部。名义预测不另强制无缺口，否则会限制风险模型在名义预测偏高时合理少买。

## 场景与选择

残差来自第8日以后的历史基础预测“实际−预测”，按完整日配对负载/光伏残差。取最近7或14个已完成日，叠加当前预测后将负载/光伏分别裁至非负，再计算净负载，等权使用。场景数不足时用已有历史，不复制以伪装样本量。

仅在1月15—31日选择7/14日窗口，另保留v1点预测作为零升级候选。候选从6000到6000，按真实计划费+5倍紧急费选最小；平局保留点预测。2月1日锁定窗口，后续只增加已完成日残差。由于v1及V2-A也使用1月开发，这不是独立测试。

所有场景共享储能计划，未赋予控制器未来场景身份。期望可加目标主要利用各时段边际误差分布，不能声称该版本已利用跨时段反馈价值或建成多阶段随机控制。

## 评价与输出

继承v1实际1月预热轨迹，2月1日从其SOC出发；12月31日通过可行计划回到6000。保持第一问的时间、效率、功率计量假设。

主对照为冻结v1/V2-A储能策略；另计算相同场景下无储能的最优经验分位数购电作为诊断，说明风险购电自身的收益。正电价和5倍紧急费下，无储能每时段选择净负载经验80%分位数（购电非负），这是此简化子问题的解，不是强行设定整个储能计划为80%分位数。

保存results/q2_v2b/、results/result2_v2b.xlsx及reports/q2_v2b_experiment.md；旧版结果不覆盖。全年总费用下降不自动证明预测风险分布已校准，必须报告紧急量、费用、弃用及分月变化。

## 验证

单场景零误差应退化到v1确定性目标；无储能七个等权样本的最优购电应为第六顺序统计量；场景期望费用由输出独立重算。复用物理、费用、时序、原件哈希、CSV和工作簿回读及故障注入检查。实际执行仍不看当前整段真实值来改变充放电，因此原有执行局限仍可能存在。
