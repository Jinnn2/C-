# 第二问V2-A：只修正日前预测偏差

## 固定部分

继承v1已选中的负载周加权、光伏7日均值及SOC惩罚参数。购电优化目标、固定全天充放电执行、效率、时间计量和终端约束均不变。不增加安全裕量、场景或日内重调度。

1月预热轨迹直接保留v1已执行结果；2月1日从该轨迹末端继续，12月31日通过正常充放电回到6000。v1所有结果文件保持不变，V2-A另存results/q2_v2a/和results/result2_v2a.xlsx。

## 偏差估计

基础预测仍为v1预测。每个历史日先生成基础预测，日结束后形成“实际−基础预测”残差；不使用实际值拟合得到的训练内残差，也不对已经修正后的残差反复叠加修正。校准初期采用冻结基础参数对1月历史进行逐日回放，这些是历史可计算的模拟预测，并非声称该参数在1月初已经上线。

每日144段分成6个4小时组。分别对负载、光伏，计算最近3或7个已完成日各组残差均值，再乘0、0.5或1的修正强度；加到当天基础预测上。修正后截断到非负，基础光伏为0的时段保持0，避免按组平移产生夜间发电。仅收集第8日起具有完整前周历史的残差。

17个候选包含一个零修正控制，其余为2个窗口×8种非零强度组合。窗口和强度只在1月15—31日开发选参；每个候选从6000运行到6000，选择实际计划费+紧急费最低者，平局按预定候选序号。基础参数本身也在1月选择过，因此这一阶段不能称独立测试。2月1日前锁定偏差参数，正式期每天只更新过去残差，不重新选参数。

## 对照与解释

主对照为同一数据、相同边界的v1储能策略。比较计划费、紧急费、总费用、误差、富余、各月及指定日期；同时保留V2-A同预测无储能结果，但不将更换预测后的无储能基线混作v1收益对照。

成本而不是MAE是选参标准；若某项误差或某些月份恶化，按实报告。全年数据已经用于v1诊断，所以这属于历史回测改进，不声称完全未触及的测试结果。

## 校验

逐段复用独立物理审计与工作簿回读；基础预测逐条与v1记录比对；零修正候选与v1同参数的1月费用对齐。检查observe/forecast顺序、输入复制隔离、已知残差组修正、非负/夜间光伏规则，以及未来数据不改变此前预测。报告参数选择与每个日内组的实际修正量，保留源数据与v1文件哈希。
