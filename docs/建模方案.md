# 微网与外部电网电力调控：建模方案

本文件整理题目阅读与建模讨论，属于方案，不是计算结果。原题及原始附件保留不改。

## 1. 统一主线

采用“预测—优化调度—滚动执行—事后评价”框架。四问共用储能物理约束，依次增加净负载不确定性、预报更新与调整费用、电价不确定性。重点是决策时刻的信息边界、预测误差的不对称成本和跨日储能价值。

## 2. 通用物理模型

每天144段，每段Δt=1/6小时。q为计划购电，e为紧急购电，c为电网侧充电输入，d为电网侧放电输出，L为负载电量，G为光伏电量，w为富余弃用电量，S为电池储电量；电量单位均为kWh，电价p为元/kWh。

- 电力平衡：q+e+G+d=L+c+w，各电量非负。不引入题目未给出的售电收入。
- 储能递推：S[t+1]=S[t]+0.9c[t]-d[t]/0.9。
- 电量边界：1200≤S≤10800 kWh，铭牌容量12000 kWh。
- 充放电限额：0≤c,d≤5000/6 kWh/段。将5000 kW解释为电网侧功率限制。
- 严格互斥：c≤(5000/6)z，d≤(5000/6)(1-z)，z为二元变量。
- 90%解释为充电和放电各自效率，往返效率81%；若采用其他解释必须独立做敏感性分析。

## 3. 第一问：确定性优化

最小化Σp[t]q[t]，紧急购电为0，满足通用约束及日末电量等于日初电量。主方案按附录初始状态取6000 kWh；若将题目解释为一般重复日，可另做共同边界电量可优化的对照，不混合结论。

以混合整数线性规划求解；线性松弛可作计算基线，但必须检查同时充放电。忽略容量等约束时，低价电存储套利需要高价大于低价/0.81。汇总六个指定10分钟段、六个4小时充放电量，以及全天购电量、费用和边界电量。

## 4. 第二问：历史预测与风险调度

每天0:00只用已获得的历史负载和光伏。先建立前日、前周、近期同类日预测基线，再用日历、滞后值、近期均值与波动构建回归或分位数模型。模型训练、验证及调参按时间顺序推进。

从历史预测残差整段抽样，构造负载与光伏的联合场景，保留时序相关性。日前购电在所有场景中一致，最小化Σp q + E[Σ5p e]。真实执行时，购电计划固定，储能可根据当前观测滚动控制，短缺通过紧急购电补足。

场景内控制不能提前获知整条未来轨迹。严格随机规划需非预见性约束；落地可使用日前场景计划加逐10分钟因果滚动执行，最终以顺序回测评价。无储能的单时段简化问题中，最小化pq+5pE[(N-q)+]对应连续净负载分布的80%分位数；该结论仅用于解释安全裕量，不能直接作为含储能模型的统一最优参数。

## 5. 第三问：预报更新与调整

0:00制定计划，6:00、12:00、18:00从实际SOC出发优化尚未执行的区间。保留每个预报的发布时间和目标时间，不能使用尚未发布的信息。

记原计划q0，调整量a，新增u=(a-q0)+，减少v=(q0-a)+。题面减少购电的结算存在两种解释：

1. 取消部分退原款、另付50%违约费：C=pq0-0.5pv+1.5pu。
2. 原计划全部付费、另加违约费：C=pq0+0.5pv+1.5pu。

后续求解前必须固定主口径，并对另一口径检验敏感性。多次调整相对0:00计划最终净额结算，还是逐次累计结算，也须明确，不能重复记账。

比较包含0:00的8种更新时刻组合，使用历史验证期选择规则，报告各时刻边际节费、紧急购电下降与调整成本。更新准确不保证调整划算。18:00预报可能通过次日光伏预测改变跨日期末电量价值，不能预先认定无效。

## 6. 第四问：波动电价

主模型按未来实时价格未知处理，根据历史电价与日历等信息预测价格，构建负载、光伏、电价联合场景。以交付时段实际价格结算作为待求解时明确的主假设，不能把全年实际电价当作每个日前决策的已知信息。

在第二、三问目标中将固定电价替换为场景电价；先完成期望成本优化，必要时增加λCVaRα(C)控制尾部费用，参数仅使用此前验证数据选择。未来实际价格已知的优化只能作为完全信息对照。

## 7. 跨日与全年评价

仅第一问明确要求日初日末相同。后续问题按S[d+1,1]=S[d,145]连续运行，不能每天重置6000 kWh。1月1日初始电量6000 kWh；2月1日起输出，1月用于历史积累及明确策略下的运行预热，不代表2月1日电量仍为6000。

采用24—48小时滚动视野或期末储电价值，避免每天将电池耗尽并将成本转移到次日。年末视野与预报越界单独处理。对比策略必须统一初始及最终电量，或修正剩余电量价值。

报告总费用及分项、紧急购电量与连续时段、弃用电量、SOC及功率可行性、调整次数和净收益、最差日与尾部费用。对照包括无储能、固定峰谷、点预测、场景优化、滚动调整和相同物理/结算条件下的完全信息下界。

## 8. 执行顺序

1. 时间计量统一与数据审计（本阶段）。
2. 第一问求解，验证能量平衡、费用和输出。
3. 第二问预测基线与全年顺序执行，再加入场景风险。
4. 第三问更新策略、结算规则及预报价值。
5. 第四问价格预测与敏感性分析。
6. 指定日期、全年指标与五份结果工作簿。

本阶段不决定调整结算歧义、不生成优化策略、不使用未来实际值训练历史决策。具体已采用的数据假设见《数据口径.md》，实测检查结果见 reports/data_quality_report.md。
